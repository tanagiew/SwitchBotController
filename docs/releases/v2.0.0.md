# SwitchBot Controller 2.0.0

Python版1.0.0の後継となる、C#／WinUI 3で全面刷新したメジャーリリースです。

## 主な変更

- Windowsネイティブに馴染むWinUI 3の新しい画面
- `config.json`に登録された全デバイスの状態を起動時・再読み込み時に取得
- デバイスごとの失敗分離と、操作結果の成功／失敗表示
- 電源状態、カーテン位置、動作状態など、SwitchBot APIが返した情報の表示
- カーテン等の操作完了後の状態追跡
- 使用する`config.json`の選択と、設定ファイルの直接編集
- .NETやWindows App SDKの事前インストールが不要な自己完結型・単一EXE配布

## ダウンロード

`SwitchBotController_v2.0.0_win-x64.zip`

SHA-256：公開直前に確定

ダウンロード後は、PowerShellで次のコマンドを実行するとチェックサムを確認できます。

```powershell
Get-FileHash .\SwitchBotController_v2.0.0_win-x64.zip -Algorithm SHA256
```

ZIPには次の2ファイルだけが含まれます。

- `SwitchBotController.exe`
- `config.json.example`

## 動作環境

- 64bit版のWindows 10 Version 1809以降、またはWindows 11
- インターネット接続
- SwitchBotアカウントとSwitchBot Cloud APIトークン

.NETとWindows App SDKはEXEに含まれるため、別途インストールする必要はありません。

## Python版1.0.0からの更新

1. 新しいZIPを別のフォルダーへ展開します。
2. 既存の`config.json`を`SwitchBotController.exe`と同じフォルダーへコピーするか、起動後の設定画面で既存ファイルを選択します。
3. `SwitchBotController.exe`を実行します。

従来の`api_key`／`device_id`形式も引き続き読み込めます。新規設定には`api_token`／`ble_mac`形式を推奨します。

## 注意事項

- コード署名を行っていないため、初回起動時にWindows SmartScreen等の警告が表示される場合があります。このGitHub Releasesから取得したファイルであることとSHA-256を確認し、警告画面の「詳細情報」から実行してください。
- 単一EXEは初回起動時に必要な実行環境をWindowsの一時領域へ展開するため、初回だけ起動に時間がかかる場合があります。
- SwitchBot Cloud APIを使用します。Hub経由の赤外線リモコンには対応していません。
- `config.json`にはAPIトークンが含まれます。公開・共有しないでください。

不具合報告は[GitHub Issues](https://github.com/tanagiew/SwitchBotController/issues)へお願いします。
